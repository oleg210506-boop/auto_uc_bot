# Безопасность и границы гарантии

Сохранены исправления 1.0.1: нормализованный PUBLIC_URL, проверка Origin и CSRF,
повторное использование токена login, same-origin referrer policy, доверенные
proxy headers. Secure HttpOnly cookies; пароль scrypt, 2FA и резервные коды;
роли owner/operator/viewer; секреты Fernet с первоначальным APP_SECRET.
Ключи не выдаются обратно в HTML/CSV, env имеет приоритет над зашифрованной базой.

Открывать панель только по HTTPS. На VPS наружу 80/443, не 8080. Не доверять
произвольным X-Forwarded-* от прямого клиента. В Compose доверен выделенный
подсетевой прокси, других приложений в эту сеть не добавлять.

SQLite synchronous=FULL, transactional intent journal, один процесс и local
flock. Два независимых диска НЕ защищены общей блокировкой. Перед сменой хоста
источник заморозить и остановить; восстановленный сервер не покупать до сверки.
Секрет в архив не включён, но архив содержит персональные данные, поэтому
хранить его вне публичного GitHub и общедоступных облачных ссылок.

Stars: после таймаута отправки нет автоматического retry. По известному ord-ID
выполняется только GET; без ID владелец запрашивает доказательство у поставщика.
Ручная привязка проверяется API и уникальностью номера. Нет кнопки "купить ещё раз"
для неизвестной операции. Даже UC не повторяются вслепую после истечения 7 дней.

Регион/номинал UC сверять вручную. Бонусы первого пополнения не считать
гарантированными. Проверка формата username не доказывает принадлежность аккаунта.
Не отключать подтверждение получателя при первом запуске. Ник UC проверяется
только при доступной API-схеме и включённой соответствующей настройке.

Нет seed-фраз TON, куки Fragment, обхода CAPTCHA, KYC или ограничений платформ.
При изменении FunPay/API неизвестные ответы останавливают выдачу для сверки.
Тесты уменьшают риск, но не доказывают отсутствие всех ошибок и сторонних сбоев.
