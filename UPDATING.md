# Обновление до 1.0.1-rc1

1. Сохраните прежние APP_SECRET и Volume /data. При наличии заказов предварительно сделайте резервную копию. Не удаляйте БД.
2. Загрузите содержимое этого ZIP в существующий репозиторий, заменив файлы. Новый autoucbot/web_security.py обязателен.
3. Railway: Start Command пустой (Dockerfile) либо python -m autoucbot; один экземпляр.
4. PUBLIC_URL=https://autoucbot-production.up.railway.app, COOKIE_SECURE=true. Не меняйте секреты и режим закупок для исправления входа.
5. Railway-прокси определяется автоматически. Если ранее задан неверный FORWARDED_ALLOW_IPS, удалите его или задайте * только для сервиса за Railway edge.
6. После успешного deploy откройте новую /login: внизу версия 1.0.1-rc1; /healthz также сообщает version.

Старая открытая форма может один раз потребовать повторного ввода после смены формата токена. Новая форма возвращается автоматически. CSRF/HTTPS/2FA не отключены. ADMIN_PASSWORD создаёт только первого владельца и не меняет уже сохранённый пароль.

Полное руководство — GUIDES/00_UPDATE_LOGIN_FIX.html во внешнем архиве.
