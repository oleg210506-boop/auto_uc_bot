# Обновление и перенос

Перед обновлением: пауза закупок, проверка незавершённых операций, резервная
копия, сохранение исходного APP_SECRET. Старый процесс остановить до первого
запуска схемы 2. Заменить полный набор исходников, не только адаптер.
Хранилище /data не менять. Первый вход и CSRF исправления сохранены.
После обновления старые live-товары выключены и не проверены. История GameCore
остаётся; автоматическая закупка по ней через FazerCards запрещена.
Новый прайс/рецепты настроить заново, прочитать USD-остаток, проверить два направления.

Переезд: панель /migration → заморозить и экспортировать → сохранить архив
и оригинальный APP_SECRET отдельно → остановить старый сервер → импортировать
архив на VPS при остановленном app → HTTPS/новый PUBLIC_URL → проверить вход →
подтвердить одну копию → observe → сверка истории → разрешение live и снятие паузы.
Команда: python -m autoucbot.transfer import /data/transfer.zip.
В Compose: docker compose run --rm --no-deps app python -m autoucbot.transfer import /data/transfer.zip.

Не выполнять `docker compose down -v`, не удалять ./data, не масштабировать app.
Откат требует подходящей версии базы и сверки операций у поставщика: старый
backup может не знать о более поздних списаниях. Подробные команды в HTML-гайде.
