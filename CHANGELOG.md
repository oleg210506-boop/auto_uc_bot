# autoUCbot — история изменений

## 2.0.1-rc1 · FunPay 429 / UID recovery
- Уважение Retry-After и увеличивающаяся пауза при HTTP 429, сохраняемая при рестарте.
- Опрос по умолчанию 30 секунд, локальный бюджет и максимум 3 последние страницы продаж за скан.
- Telegram-предупреждение FunPay один раз на активный инцидент.
- Серверный HTTP/HTTPS-прокси для FunPay через FUNPAY_PROXY_URL, без влияния на FazerCards.
- Кнопка безопасного ручного восстановления UID из переписки после проверки оплаты и отсутствия закупки.
- Напоминания только после первого подтверждённого исходящего запроса UID; неизвестные отправки не повторяются автоматически.
- Сохранены FazerCards UC/Stars, финансовая история, 2FA, миграция и настройки.

# 2.0.0-rc1 · 2026-10-08
- Новый синхронный и асинхронный FazerCards транспорт: UC, Stars, баланс, каталог,
  проверка UID, подписка, GET статусы, подписанные вебхуки.
- Stars через предоплаченный USD-баланс FazerCards, без TON-кошелька и browser cookies.
- Отдельные настройки направлений, шаблоны, лимиты, подтверждения и Telegram-тревоги.
- Персистентные отдельные намерения пополнений, защита от повторного события и
  повторной отправки unknown, отдельное исполнение двух оплаченных заказов.
- Составные UC и агрегирование Stars, проверка всего бюджета до первой выдачи.
- Настоящий API баланс, резервы, возобновление при достаточном остатке.
- Статистика по направлениям, подтверждённая/оценочная себестоимость, CSV.
- История GameCore сохранена, новые GameCore live-закупки заблокированы.
- Миграция схемы 1→2 с копией; подписанный перенос архива; восстановление offline.
- Compose/Caddy для VPS/домена; один экземпляр, постоянные данные.
- Исправления CSRF входа 1.0.1 сохранены.
