# autoUCbot 2.0.0-rc1 — FazerCards UC + Telegram Stars

Одна закрытая FastAPI-панель, один последовательный worker и SQLite на постоянном диске.
Новые live-закупки выполняются **только через FazerCards**. GameCore оставлен для
сверки старой истории. Stars также закупаются через FazerCards за баланс USD:
это **не** прямой перевод TON на Fragment и не клиент Tonkeeper.

## Где инструкции владельца
Внешний архив содержит `START_HERE.html` и `GUIDES/*.html` (открыть в Chrome).
Установка и вход у владельца уже выполнены: сначала руководство обновления,
затем шаг 2 основного руководства — подключение FazerCards.

## Railway
Заменить файлы репозитория всем содержимым этого ZIP. Start Command:
`python -m autoucbot` либо команда из Dockerfile. Одна реплика. Постоянный Volume
`/data`. Не менять `APP_SECRET`, не удалять базу. Во время первой миграции схемы
старый процесс должен быть остановлен. Обновление переключает старую установку
в observe, отключает новые покупки и требует перенастройки live-товаров.
Не откатывать старый код поверх уже мигрированной схемы без восстановления копии.

## Переменные
См. `.env.example` для Railway и `.env.vps.example` для Docker Compose.
Ключи FazerCards вводятся в панели → Подключения. `FAZER_API_KEY` и
`FAZER_WEBHOOK_SECRET` — альтернативные env. Seed TON, куки Fragment не нужны.
Пароли и ключи не коммитить. Заполненный `.env` не включён.

## VPS и домен
`compose.yaml` + `deploy/Caddyfile`. Постоянная база — `./data` на сервере.
Вначале установите Docker Engine и Compose по официальной инструкции для вашей ОС.
`cp .env.vps.example .env`; сохраните старый APP_SECRET и задайте APP_DOMAIN.
`docker compose config --quiet`; `docker compose build`.
Порядок переноса — GUIDES/05_MIGRATION.html; нельзя включать две копии одновременно.

## Режимы и финансы
DEMO полностью локальный. OBSERVE читает реальные сервисы, но не выдаёт товар.
LIVE требует env-разрешение, checklist панели и отдельное снятие паузы.
UC/Stars имеют независимые лимиты, тексты, подтверждения и паузу. Общий баланс
читается из `/balance` в USD. Курс USD/RUB для прибыли задаёт владелец.
Подписка FazerCards и реальная закупка оплачиваются; бот не покупает подписку сам.
Цены и доступность сверяйте в своём кабинете/API, не по значениям из примеров.

## Разработчику
- `ARCHITECTURE.md` — маршрутизация, схема, состояния, контракт адаптеров.
- `PROTOCOL_SOURCES.md` — проверенные первичные источники и ограничения API.
- `SECURITY.md` — инварианты, неизвестные операции, перенос, секреты.
- `TESTING.md` — локальные тесты и то, что не проверяется без реальных доступов.
- `UPDATING.md` — обновление без потери истории.

Нет автоматической повторной покупки после неизвестного ответа Stars.
При наличии точного номера ord-... проверяется статус. Если номер потерян,
нужна ручная сверка у поставщика; сходство получателя/суммы недостаточно.
